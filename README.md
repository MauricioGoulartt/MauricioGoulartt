# Mauricio Goulart

**Engenharia de software · Backend, arquitetura e integrações**

Meu foco é construir APIs e conectar sistemas. Compartilho aqui implementações e estudos sobre organização de código, modelagem de domínio, persistência e comunicação entre serviços.

## Projetos para explorar

### [SocializeMe API](https://github.com/MauricioGoulartt/socializeme-api)

Domínio, casos de uso e persistência em uma API social.  
TypeScript · Express · MongoDB

### [SmartRanking](https://github.com/MauricioGoulartt/smartranking-api)

Jogadores, categorias e desafios organizados em módulos, com DTOs e validação.  
TypeScript · NestJS · Mongoose

### [Mensageria com RabbitMQ](https://github.com/MauricioGoulartt/microservices-RabbitMQ)

O caminho de uma mensagem: requisição HTTP, fila e consumidor.  
Node.js · RabbitMQ · Docker Compose

### [API com testes HTTP](https://github.com/MauricioGoulartt/tdd-clean-api)

Rotas de usuários, serviços e testes de comportamento com mocks.  
TypeScript · Express · Jest · Supertest

Cada README apresenta o escopo, o mapa do código e as limitações do projeto. São estudos públicos; a presença de código ou testes não equivale a prontidão para produção.

## Foco técnico

- **APIs e domínio:** contratos, validação e separação de responsabilidades.
- **Integrações e mensageria:** comunicação entre serviços e fluxos assíncronos.
- **Qualidade de código:** testes HTTP, organização em camadas e documentação do comportamento.
